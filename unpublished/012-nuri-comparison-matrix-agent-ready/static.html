Research notes.

Competitor architecture changes quickly. Yellow cells are intentional: they are the places to re-check before publishing a public claim.

Cash App

Bitcoin balances are custodial; Lightning is supported. Cash App also added stablecoin support in 2026. Source ↗

Bitkey

Seedless 2-of-3 multisig with independent emergency exit; Bitcoin-focused hardware + app model. Source ↗

Blitz

Self-custodial Bitcoin & Lightning on iOS, Android and web; uses a 12-word seed. Blitz is open source under Apache 2.0, not MIT. Source ↗

Muun

Self-custodial Bitcoin wallet using multisig; native apps are published under the MIT license. Source ↗

Strike

Bitcoin balances are custodial; Bitcoin and Lightning transfers are supported. Source ↗

Wallet of Satoshi

Now offers a self-custody mode, but it uses a 12-word recovery phrase. Source ↗

Bitrefill

Strong living-on-crypto benchmark with Visa card and SEPA withdrawal; users can connect external wallets rather than Bitrefill being a like-for-like self-custody wallet. Source ↗

Bitwala

Current positioning includes seedless self-custody plus Visa and bank transfers; older vault documentation reflects a different legacy architecture, so some cells remain yellow. Source ↗
