PROBLEM

Your agent holds the keys to your life — in a plain file

  • 39% of professional developers already run Claude Code at work; millions run personal agents on their own machines
  • The agent's wallet keys, logins and passwords sit in software on that machine
  • One malware infection: drained wallet, leaked logins, forged signatures
  • Agent payments (x402) make it worse — an agent that can pay holds keys worth stealing
  • Hardware security exists — but it was built for military and enterprises, sold in bulk, at $58–349. Normal people never got an affordable one
Sources: JetBrains dev survey 2026 · x402 payments live on Base since 2025
SOLUTION

A security keycard that says yes or no

Nuri Card — an NFC security keycard with a certified secure element. The agent keeps a low-value session key; the card holds the high-value keys. Tap = approve. No tap = nothing moves.

  • Bitcoin MuSig2 multisig co-signer — key generated on-card, never leaves it
  • Cryptocurrency hardware wallet for Ethereum — EVM keys in the secure element
  • OATH-TOTP authenticator — one-time codes without a phone
  • SSH hardware security key — in daily production use on our servers
  • FIDO2 passkey with WebAuthn PRF — log into any site through the card
Working firmware on real hardware — one Java Card, five functions, MIT-licensed
HOW IT WORKS

Half-wallet, full control

  • Agent gets a session key with a spending cap
  • Card holds the owner key; above the cap, a tap is required
  • Spending policy lives on the card: per-payment limit, daily limit, allowed recipients
  • Card lost? Agent key alone can't move the money; recover with a backup card
  • Three versions
  • Basic — PIN, under $10 to build. The everyone version
  • Medium — fingerprint inside the secure element (Feitian BioCARD platform, ~$25–45 landed)
  • Pro — Bluetooth: card + BT sleeve/dock for the phone and agent (Feitian bR500, ACS ACR1255U-J1 ~$59 exist today). One card to stock; the passive card stays the trust anchor
WORKING TODAY

Not a concept — running firmware on real hardware

  • All five functions run on the Feitian BioCARD fingerprint platform and NXP J3R180 JCOP4 cards (secp256k1 for Bitcoin)
  • Applet code public (MIT) — audit it, load it on a blank card, verify keys never leave the secure element
  • The SSH applet is not a demo: it secures our production servers today
  • Cheap blank cards ($2.55–8.90 on Alibaba) can run the same firmware — the Basic tier
