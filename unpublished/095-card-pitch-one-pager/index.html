Nuri Card

The first mainstream-affordable security keycard: passkey, HSM and crypto half-wallet — for AI agents and for everyone who runs a computer.

Problem

Millions now run personal AI agents on their own machines (39% of professional developers use Claude Code at work). The agent's keys, logins and wallets sit in plain files on that machine. One piece of malware drains the wallet, leaks every password, forges every signature. Agent payments (x402) make it worse: an agent that can pay holds keys worth stealing.

Hardware security exists — but it was built for the military and enterprises, sold in bulk, at $58–349. Normal people never got an affordable one.

Solution

A security keycard. An NFC card with a certified secure element that holds your passkeys, wallet keys and logins. The agent keeps a low-value session key; the card holds the high-value keys. Tap = yes. No tap = nothing moves.

Three versions:

  • Basic — PIN, under $10 to build. The everyone version.
  • Medium — fingerprint sensor, match inside the secure element (Feitian BioCARD platform, ~$25–45 landed).
  • Pro — Bluetooth: card plus a BT sleeve/dock that talks to your phone and agent continuously (existing BT readers: Feitian bR500, ACS ACR1255U-J1 ~$59). One card to stock, the passive card stays the trust anchor.

Working firmware today, one Java Card (public, MIT). One card, five security functions:

  • Bitcoin MuSig2 multisig co-signer — key generated on-card, never leaves it
  • Cryptocurrency hardware wallet for Ethereum — EVM keys in the secure element
  • OATH-TOTP authenticator — one-time codes without a phone
  • SSH hardware security key — in daily production: our servers are SSH'd with it today
  • FIDO2 passkey with WebAuthn PRF — log into any site through the card

The wave we ride

Hardware security is going mainstream right now: Apple supports external security keys for Apple Account and passkeys on keys since iOS 16.3; Android supports passkeys on NFC keys since Android 9. YubiKeys entered 350 Best Buy stores in Oct 2025 with $25–29 entry keys. The FIDO Alliance counts ~5 billion passkeys in use (May 2026), and new NIST guidance prefers hardware-bound keys at the highest assurance level. The behavior is mainstream — the affordable, agent-native card is missing.

Working today

All five functions run as firmware on real hardware: the Feitian BioCARD fingerprint platform and NXP J3R180 JCOP4 cards (the secp256k1 needed for Bitcoin). The applet code is public (MIT) — anyone can audit it, load it on a blank card, or verify the keys never leave the secure element. The SSH applet is not a demo: it secures our production servers today.

Business

Hardware with margin (Yubico sold 32M+ keys; Tangem 6M+ cards), plus the closed tier: device attestation, spending-policy engine, fleet management, recovery. Open-source the applets and protocol for developer trust — the closed peers (Tangem) won on distribution, the open peers (Satochip, Keycard) stayed tiny; we take open trust plus retail distribution. Sell dev-first online like YubiKey did; bundle with Claude Code, OpenClaw and x402 agent platforms.
